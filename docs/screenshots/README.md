# 截图目录

请将小程序截图放在此目录下，推荐命名：

| 文件名 | 对应页面 |
|--------|----------|
| `home.png` | 首页 |
| `coach-list.png` | 教练列表 |
| `coach-detail.png` | 教练详情 |
| `booking.png` | 预约日历 |
| `order.png` | 订单页面 |
| `profile.png` | 个人中心 |
| `review.png` | 评价页面 |
| `favorites.png` | 我的收藏 |

## 截图要求

- 尺寸：推荐 375 x 812（iPhone X 比例）
- 格式：PNG 或 WebP
- 内容：使用模拟数据，不要包含真实用户信息
- 工具：微信开发者工具截图或真机截图
